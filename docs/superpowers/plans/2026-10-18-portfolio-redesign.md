# Portfolio Redesign (React+Vite) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild mahdikhadem.com as a dark, editorial, single-page academic portfolio (React+Vite+TS+Tailwind) that preserves all existing posts/projects prose and URLs, adds Publications and Teaching & Service, and deploys to the existing GitHub Pages repo.

**Architecture:** New Vite+React+TS app scaffolded in `SMMKhadem/` (in place; Hugo files removed in Task 1). All copy in `src/data/portfolio.ts`; posts as MDX routes; react-router SPA with `404.html` fallback so legacy slugs resolve on Pages. New GH Actions workflow builds `dist/` and pushes to `mahdmahd/SMMKhadem.github.io`.

**Tech Stack:** Vite 6 + React 18 + TypeScript + Tailwind v4 + react-router + lenis (smooth scroll). Vitest + Testing Library for tests. No GSAP (CSS + IntersectionObserver covers marquee/reveal; keeps bundle lean).

**Spec:** `docs/superpowers/specs/2026-10-18-portfolio-redesign-design.md`

## Global Constraints

- Rebuild layout grammar/interaction patterns ONLY — no code, copy, or images from `portfolio-crawl/portfolio/assets` or `photos/` (sold template; owner doesn't own it).
- Display type: oversized uppercase tight-tracked, metallic gradient `linear-gradient(180deg,#fff,#8a8a8a)` + `background-clip:text`; eyebrows/nav/meta: `ui-monospace`, uppercase, wide tracking, 12–14px.
- Tokens: `--bg:#050505; --panel:#0b0b0b; --border:rgba(255,255,255,.12); --text:#f5f5f4; --text-dim:#a3a3a2; --accent:#e8e4dc; --accent-hover:#d6d1c6; --on-accent:#050505`. Container max 72rem; section padding 96–128px vertical; buttons pill.
- Legacy slugs frozen and routable: `/posts/<slug>/` (4 posts), `/projects/<slug>/` (11 pages), `/about/`, `/contact/`. Post/project prose byte-identical except owner-approved rot fixes.
- `prefers-reduced-motion` disables marquee/reveal/tilt. Lighthouse 95+ homepage. Hero art: abstract/duotone (no photo); avatar.jpg (266px) only at natural size.
- Contact set: email `Smmehdikhadem@gmail.com`, LinkedIn `/in/mohammad-mehdi-khadem-09bb8910b/`, GitHub `mahdmahd`, ORCID `0009-0005-4294-7934`, Formspree `xkonleag` (verify; mailto fallback if dead). Telegram/Twitter-Instagram dropped.
- Cards render Paper/Code/Demo buttons ONLY for verified URLs. Unverified PMID on weight-trajectory page is dropped.
- No backend, no analytics, EN only, LTR. Frequent commits; one task = one reviewable deliverable.

## Review Focus

- A legacy URL (`/posts/mem1/`, `/projects/project-6/`, etc.) shared from a citation 404s or serves the SPA shell without content → every slug must render its content on direct load (test: fetch built `dist/` route via preview server, assert content present).
- A Paper/Code/Demo button points at a dead or wrong URL (e.g. reused PMID) → link audit test pins every external URL to HTTP 200 (test: script asserts status codes for all URLs in `portfolio.ts`).
- The Formspree endpoint is dead and the form silently swallows submissions → test asserts either a live endpoint check at build or the mailto fallback rendering path.
- Motion (marquee/reveal) runs under `prefers-reduced-motion` → test asserts media query disables animations.
- The CV download 404s → test asserts `public/cv.pdf` exists in build output and the header/section links resolve to it.
